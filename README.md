## 고지

### 유튜브 / 유튜브 api 서비스
* 모든 미리보기, 동영상은
    * 다운로드 받아서 제공하고 있지않아요.
    * 유튜브 서비스를 이용해 제공하고 있어요.
* 모든 재생은
    * YouTube IFrame Player API를 이용하고 있어요.
* 모든 재생으로 발생한 조회수는
    * 유튜브 정책에 따라 정당한 창작자에게 정당하게 돌아갈거예요.
* 자세한 내용은 직접 확인해보세요.
* [링크] (유튜브 api 서비스 약관)
* [링크] (유튜브 개발자 정책)

### 저작권
* 모든 미리보기, 동영상의 저작권은 창작자에게 있습니다.
* 모든 미리보기, 동영상은 해당 창작자에게서 허가를 받은 것만을 사용하고 있어요.
    * 과거에 업로드 된 동영상
    * 앞으로 업로드 될 동영상
* 모든 창작자는 언제든지 추가, 제거를 명령 할 수 있습니다.

### 라이선스
* 이 프로젝트는 APGL 3.0 라이선스를 사용하고 있어요.
	* 누구나 사용, 복제, 수정, 배포, 웹서비스 할 수 있습니다.
	* 배포, 웹 서비스 시
		* 소스코드를 공개해야합니다.
		* APGL 3.0 라이선스를 유지해야합니다.
* 라이선스 미적용 범위 / 라이선스 미적용 / 라이선스 예외
	* 명단 내부에서 사용 중인 모든 유튜브 동영상 링크는 라이선스에 적용받지 않습니다.
	* 명단 내부에서 사용 중인 모든 유튜브 동영상 링크는 라이선스를 적용받지 않습니다.
	* 명단 내부에서 사용 중인 모든 유튜브 동영상 링크는 라이선스와 무관합니다.
	* 명단 폴더 내부에 있는 모든 파일은 라이선스와 무관합니다.
* 자세한 내용은 해당 [라이선스](LICENSE)를 직접 확인해보세요.
